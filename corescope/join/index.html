Add an observer

Digitaino CoreScope · Austin · the analyzer

An observer forwards the LoRa packets it hears to the analyzer. Your node keeps its normal role on the mesh.

What you need

Internet access for the node. Two ways:

Radio with WiFi

Radio connects by itself. No computer.

  • Heltec V3 / V4
  • LilyGo T-LoRa
  • Station G2
  • Seeed T1000-E
  • Any ESP32 board

Radio + computer

Computer reads the radio over USB and stays on.

  • RAK4631 and other nRF52 boards. No WiFi, so this is the only option
  • Pi, mini-PC, Mac, or Home Assistant box
  • Also works if you don't want to reflash

Same values for every method.

Radio with WiFi

Flash an observer build at observer.gessaman.com.

Open the serial console at 115200 baud, or use config.meshcore.io in Chrome or Edge. Paste:

set mqtt1.preset custom
set mqtt1.server obs.digitaino.com
set mqtt1.port 443
set mqtt1.audience obs.digitaino.com
set mqtt.iata AUS
reboot

If WiFi isn't set up, add before reboot:

set wifi.ssid YOUR_NETWORK
set wifi.pwd YOUR_WIFI_PASSWORD

Slots mqtt1–mqtt3 run at the same time. If MeshTexas or MeshMapper uses mqtt1, use mqtt2 or mqtt3.

Radio + computer

Pick one. Follow its install docs and add a custom broker.

Home Assistant
MeshCore integration over USB, WiFi, or Bluetooth. Check Use MeshCore Auth Token. Leave username and password blank.
meshcore-packet-capture
Python, serial. The installer asks for a broker. Choose custom.
meshcoretomqtt (mctomqtt)
Serial repeaters and room servers, including RAK. Handles several brokers at once.
MeshMonitor
Analyzer Observer, then Custom. URL wss://obs.digitaino.com, auth Signed token. Needs the node's private key and a Companion device.

Check it

get wifi.status        → connected, with an IP
get mqtt1.audience     → obs.digitaino.com
get public.key         → your node's identity

Find your node on the observers page. Takes a few minutes.

If it doesn't work

Connects, then drops
Audience must be exactly obs.digitaino.com. No wss://, no port.
Connects, nothing on the map
IATA must be AUS.
Drops every minute or two
Keepalive under 100s. Use 45–60.

Unofficial. Run by Digitaino in Austin. Your node can report to other networks at the same time.
